#### Finding 2 — Negation count vs scope in short labels
- **Status:** **Closed**
- **Analysis:** `tests/pmg.test.js:84–91` replaces negation counting with qualifier-token pairs:
  ```js
  const QUALIFIERS = new Set(["with", "without", "non", "no", "not"]);
  const negations = (s) => {
    const ws = words(s.replace(/±/g, " with or without "));
    return ws
      .map((w, i) => (QUALIFIERS.has(w) ? `${w} ${ws[i + 1] ?? ""}` : null))
      .filter(Boolean)
      .sort();
  };
  ```
  Each qualifier is coupled to the specific word it qualifies (`ws[i + 1]`). #### Finding 3 — Numeric normalization accepting negative maximum dose

### 2. New Defects and Weakenings
